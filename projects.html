Desktop Apps

To set time limits for myself while painting, I wanted to have a timer that would always stay on top on my desktop.

So I started working on exactly that in Godot.

Right now, I'm still putting the finishing touches on it. As soon as the timer is ready, I'll post a link to it here for you.

I see this project as the first in a series of apps that run on the desktop to provide a little extra help.

Game Development

Together with my partner, I spend my free time working on using the 3D models I've created and animated for our own video games.

So far, we've mainly created various prototypes and familiarized ourselves with how the Godot engine works.

Now we're refining a fun gameplay concept and focusing on game design. I'll keep you updated on this as well.
